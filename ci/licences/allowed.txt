# The licences Vectispire may distribute a component under, and the components reviewed one by one.
# Read by ci/licences/check.py; the reasoning is docs/en/LICENSES.md.
#
#   licence   | <scope: all, or jar,npm,image> | <SPDX id> | <why it can ship inside an Apache-2.0 distribution>
#   component | <jar|npm|image> | <name> | <the licence it is distributed under> | <the ids its metadata declares, or -> | <why>
#
# A jar name is <group>/<artifact>, `<group>/*` for a whole group; an npm name is the package; an image
# name is the distribution package. A component line vouches for the declared ids it lists and nothing
# more: a new version declaring another licence fails until it is read again. A component line that
# matches nothing fails too — the list only holds what ships.
#
# **What is never added here**: GPL or AGPL for a jar or the interface, SSPL, the Commons Clause, or a
# licence nobody has read. LGPL only through a component line saying how it is used.
